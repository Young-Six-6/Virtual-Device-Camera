# 本机 Web UI

程序启动后会在 `127.0.0.1:<web_port>` 提供轻量管理页；默认端口为 8765。控制台会打印完整地址，地址片段内含本次进程随机生成的访问令牌。复制该地址到本机浏览器打开。服务只绑定 loopback，不接受局域网连接；接口要求该令牌并校验 Host/Origin。

页面提供：

- 查询虚拟 USB 驱动接口、摄像头运行状态、RGB 输入管道连接/帧状态及控制管道监听状态。
- 预览当前摄像头的 YUY2 输出画面。
- 修改已运行摄像头的输出宽高、RGB 输入管道名、控制管道名和控制管道访问范围。
- 将成功应用的设置写入 EXE 同目录的 `camera.ini`，下次启动继续使用。

支持宽度为偶数且在 2–4096 之间、高度在 1–2160 之间的分辨率。摄像头 2 仅在以两个视频文件启动时出现。改分辨率会重新枚举设备，视频客户端需重新打开摄像头。RGB 管道输入模式下改管道名会断开旧发送端并创建新监听；发送端连接到新管道后即可继续工作，无需重启摄像头应用。若当前以 MP4 输入启动，新 RGB 管道名会保存用于之后的管道模式启动。改控制管道名会立即重建命令服务。

控制管道默认使用 `control_pipe_access=everyone`，安全描述符允许 Everyone、对象所有者和 SYSTEM；也可改成 `users`（本机 BUILTIN Users 组）或 `owner`（对象所有者）。控制与 RGB 输入管道访问权限互相独立；RGB 输入默认使用 `rgb_pipe_access=owner`。管道均拒绝远程客户端。旧版单一 `pipe_access` 配置会迁移为两条管道的相同权限，后续保存改用独立配置项。Web UI 自身仍只监听本机，并由每次启动的随机令牌保护。配置示例在仓库的 `config/camera.ini`；构建只在输出目录尚无 `camera.ini` 时复制默认文件，不覆盖已有用户配置。

如果 Web UI 端口被占用，程序会报告启动失败。编辑 EXE 旁边 `camera.ini` 的 `web_port` 后重启程序即可更换 Web UI 端口。
