# 本机 Web UI

程序默认以控制台应用启动，双击后会保留控制台并显示运行日志。启动时会打印 Web UI 地址和本次进程的随机访问令牌；复制完整地址到本机浏览器打开。默认只绑定 `127.0.0.1`。可在设置页切换网络监听，开启后立即绑定所有 IPv4 网络接口；接口仍要求随机令牌并校验 Host/Origin。访问令牌不会保存在配置文件中，Web UI 日志视图会对令牌做脱敏。

页面提供以下功能：

- 查看虚拟 USB 驱动类型、摄像头连接状态、当前 USB 模式、输出帧率、RGB 输入管道和控制管道状态。
- 选择 RGB 命名管道或程序内置 OBS WebSocket 输入。OBS 连接由用户态程序自己的后台线程管理，自动重连，不需要另行启动 `ObsLocalPine.py`；管道输入仍保留供外部发送端使用。
- 配置 OBS 主机、端口、场景/来源名称、抓帧频率、是否跟随 OBS 画布，以及纯色测试画面。OBS 状态、重连错误和最近帧信息显示在设备状态卡片中；预览仍使用实际进入摄像头链路的画面。
- 在预览上方实时显示虚拟 USB 模式与实际完成帧率。帧率按 USB 视频帧完成事件滚动统计；没有持续输出帧时会回落到 `0 fps`。
- 在摄像头列表中图形化添加或移除虚拟设备，最多 7 路；至少保留一路。新增设备立即枚举到虚拟 USB 总线，共用当前视频输入源并沿用当前选中摄像头的画面参数；新增设备使用该槽位对应的独立 VID/PID 和默认名称。移除后立即断开；活动设备配置会写入 `camera.ini` 并在下次启动恢复。
- 分别设置每路摄像头的分辨率、1–60 fps 默认上限、VID、PID、厂商字符串、设备名称，以及 YUY2/MJPEG 格式开关。至少保留一种格式。新增设备默认继承当前摄像头的分辨率、帧率和格式，并分配独立 VID/PID。
- 修改 RGB 输入管道、控制管道和控制管道访问范围。
- 使用“允许网络访问”按钮切换 WebUI 监听范围。关闭时仅本机可访问；开启时页面会显示红色警告，并允许其他设备通过本机 IPv4 地址访问。
- 查看最近运行日志；日志继续写入控制台，Web UI 展示的日志尾部最多 32 KiB，并脱敏访问令牌。
- 使用复选框隐藏或恢复控制台。隐藏后程序、摄像头和日志仍继续运行；双击托盘图标，或右键托盘图标后选择“显示控制台/隐藏到托盘”，可来回切换。右键菜单也提供退出。首次启动默认显示控制台；托盘隐藏状态只对当前进程生效。
- 注入自定义 CSS 和 JavaScript 扩展页面主题。CSS/JS 会保存在 `camera.ini`，应用后页面自动重新载入以启用新主题。

## 摄像头参数与热更新

分辨率宽度必须是 2–4096 之间的偶数，高度为 1–2160；目标帧率范围为 1–60 fps。fps 是 UVC 描述符里的默认帧率上限，YUY2 会根据当前虚拟 USB 带宽自动限制可行帧率；USB 主机也可能选择更低帧率。界面显示的是实际完成输出的帧率，而不是配置值。

应用某一路的分辨率、帧率、设备身份或格式后，用户态程序会在现有虚拟 USB 总线上仅重新枚举该路摄像头。新增或删除设备也只会插入或移除对应虚拟 USB 子设备；不会安装、更新或卸载驱动，也不要求重启系统。Windows 视频客户端可能仍持有旧的视频流句柄，因此必要时关闭并重新打开该客户端中的摄像头。RGB 输入管道改名会关闭旧监听并创建新监听；发送端连接新管道后即可继续使用。MP4 输入模式下修改 RGB 管道名会保存，供之后切换到管道输入时使用。控制管道改名会立即重建命令服务。

## OBS WebSocket 输入

在“视频输入源”中选择 OBS WebSocket 后，程序直接连接 OBS WebSocket v5，并通过 `GetSourceScreenshot` 获取指定场景或来源的 JPEG 截图。默认配置沿用旧连接器的 `localhost:4458`、`test1` 场景名和 10 fps；OBS 的 WebSocket 服务端口、密码和场景名必须与这里一致。OBS 默认端口若不同，请在页面修改。

“自动跟随 OBS 画布尺寸”开启时，输入按 OBS 基础画布尺寸截图；若 OBS 不提供画布设置，则回退到当前摄像头输出尺寸。关闭时也按当前摄像头输出尺寸取图。进入用户态后，画面会按正在协商的摄像头分辨率缩放，因此 OBS 画布、脚本和驱动不再需要手工保持相同分辨率。抓取线程独立于 USB 帧回调；OBS 暂时不可用时，连接状态会显示错误并按递增间隔自动重连。可以启用纯色测试画面检查摄像头链路，无需连接 OBS。

OBS 密码以 Windows 当前用户 DPAPI 加密后写入 `camera.ini`，不会通过状态接口回传。为避免无 TLS 的 WebUI 把 OBS 密码发到局域网，密码只能通过 `127.0.0.1` 或 `localhost` 页面设置/清除；其他设置仍可按 WebUI 网络访问策略远程修改。将配置文件复制到另一 Windows 用户下时，程序仍可启动，WebUI 会提示在本机重新输入 OBS 密码；保存其他设置时会保留原加密值，避免意外清除。

带命令行 MP4 文件启动时，文件输入优先，WebUI 会锁定输入源选择；不带 MP4 启动时，管道/OBS 可在线切换并保存。

USB 模式表示当前虚拟总线为 `SuperSpeed` 或 `USB 2.0 高速`，不是物理 USB 接口测速。720p YUY2 在 USB 2.0 高速下受等时端点带宽限制；可同时启用 MJPEG 以供客户端选择压缩格式。

## 网络访问

`web_allow_network=false` 是默认值，服务只接受本机回环访问。开启后会立即重绑到 `0.0.0.0:<web_port>`，设置保存到 `camera.ini`，之后启动也会保持开启；再次按按钮即可关闭并恢复 loopback 绑定。网络模式使用本机 IPv4 地址和控制台显示的同一进程令牌访问，例如把控制台 URL 中的 `127.0.0.1` 换成本机 LAN IPv4 地址。Host 必须匹配请求实际到达的本机地址，Origin 必须与 Host 同源，以拦截 DNS rebinding。HTTP 不加密，且 Windows 防火墙可能仍会阻止入站连接；只在可信网络启用。关闭后远程页面会断开，需在本机重新打开。

## 主题脚本

CSS 和 JavaScript 分别注入页面 `<head>`。JavaScript 在页面 DOM 创建前同步运行；需要访问页面元素时，把代码放入 `DOMContentLoaded` 回调。自定义脚本可以修改本机管理页的显示和行为，并以当前页面权限运行，因此只应保存自己信任的代码。主题文本以 UTF-8 十六进制写入 `custom_css_hex` 和 `custom_js_hex`，以保留换行、等号和非 ASCII 字符；请通过 Web UI 编辑，不要手工拆改编码后的值。

## 配置文件

所有摄像头参数、管道名称/权限、主题和 `web_allow_network` 网络监听设置保存在程序目录的 `camera.ini`。初始模板位于 `config/camera.ini`；构建只会在输出目录中尚无配置文件时复制模板，不覆盖已有配置。

摄像头键按编号成组，例如 `camera1_enabled`、`camera1_width`、`camera1_height`、`camera1_fps`、`camera1_vid`、`camera1_pid`、`camera1_manufacturer`、`camera1_name`、`camera1_yuy2` 和 `camera1_mjpeg`。`cameraN_enabled` 保存该槽位是否创建；旧配置缺少此键时只默认启用第一路。VID/PID 使用十六进制；`0x` 前缀可省略。`cameraN_name_custom=false` 表示沿用输入模式对应的默认名称；Web UI 将名称改为其他值后会保存为自定义名称。

Web UI 端口由 `web_port` 设置，默认 8765。若端口被占用，程序会报告启动失败；修改配置后重新启动程序即可更换端口。
